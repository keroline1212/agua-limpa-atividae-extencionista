# 💧 Água Limpa é Vida

Projeto desenvolvido como parte de uma **atividade de extensão universitária** do curso de **Análise e Desenvolvimento de Sistemas**.

##  Objetivo

O projeto **Água Limpa é Vida** tem como objetivo promover a **conscientização sobre a importância da água, seu uso consciente e a preservação ambiental**, além de apresentar informações relacionadas ao saneamento básico e à realidade da comunidade de Viamão - RS.

A proposta é utilizar a tecnologia como uma ferramenta de **informação e conscientização da comunidade**.

##  Sobre o projeto

O site apresenta informações sobre a importância da água, preservação ambiental, uso consciente e saneamento básico, buscando transmitir o conteúdo de forma simples e acessível.

O projeto foi desenvolvido e publicado utilizando o **GitHub Pages**.
